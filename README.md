# Logistics Audit Hub

Criar um aplicativo de auditoria de Housekeeping e Auditoria de Processos para área logística.

O aplicativo deve permitir:

- Realização de auditorias 5S

- Registro de não conformidades

- Inserção de fotos

- Plano de ação com responsável e prazo

- Dashboard com indicadores

- Histórico das auditorias

- Cadastro de áreas

- Cadastro de auditores

- Controle de pontuação

O aplicativo deve ser responsivo para celular.
